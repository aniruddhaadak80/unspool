# Security Policy — unspool

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| main    | ✅ Yes (current)   |

## Reporting a Vulnerability

Report security issues privately to the maintainer (no public GitHub issue).
Include reproduction steps, affected versions, and impact.

## Scope

In scope: `unspool` source, `src/`, `.github/workflows/*`.

Out of scope: third-party FalkorDB instances used by `live-verify`.

Thank you for helping keep unspool reliable.
